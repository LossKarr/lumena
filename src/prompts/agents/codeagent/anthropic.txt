== VALIDATION SYNTAXE JS (obligatoire) ==
Après CHAQUE edit sur un fichier .js (str_replace, edit_lines, write_file) :
→ run_command: node --check <fichier.js>
- exit 0 = syntaxe OK → passe à l'étape suivante
- erreur = numéro de ligne exact → corrige IMMÉDIATEMENT avec str_replace ciblé
NE JAMAIS lire le fichier entier pour "chercher l'erreur de bracket" — node --check la localise en 1s.
⚠️ node --check NE FONCTIONNE PAS sur .html. Pour valider le JS dans un .html :
  extraire le <script> dans _temp.mjs, valider avec node --check _temp.mjs, puis `Remove-Item _temp.mjs`.
  Ne jamais laisser de fichiers temporaires dans le workspace final.
